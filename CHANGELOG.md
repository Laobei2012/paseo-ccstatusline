# Changelog

## 0.1.0

Initial public release preparation for unmodified Paseo 0.14.0.

- Composer status pill with context, 5-hour and weekly usage percentages.
- Click-open Text and Colored views that reuse supported ccstatusline settings and remember the selection across agents until reload.
- Powerline themes, horizontal row scrolling and mouse wheel support on web/desktop.
- Model, branch, memory, token, usage, reset timer and thinking widgets, plus Claude skill and output-style information when available.
- Public setup documentation, sample-data screenshots and marketplace metadata.

Provider usage is host-wide and cannot identify an agent's active account. Multiple matching reports hide usage values. Hover uses the standard host's plain-text tooltip. Native touch gestures are not yet verified.
