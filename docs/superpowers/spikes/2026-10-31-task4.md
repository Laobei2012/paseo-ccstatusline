# Task 4: daemon facts

Test-first commit: `f6c620c`. Before implementation,
`npm test -- test/server-facts.test.ts` failed at collection because
`server/facts.ts` did not exist. After implementation, **15 tests passed**.
Every test sets `CLAUDE_CONFIG_DIR` to a temporary directory and removes its
fixtures afterward. No real Claude settings were read by the tests.

The `facts.read` RPC returns branch, memory and output style, cached for five
seconds by cwd and provider. Git uses `execFile` with a two-second timeout;
plain or missing directories keep memory and hide the branch. On macOS, memory
uses active plus wired pages from `vm_stat`, with total minus free memory as
the fallback, matching ccstatusline 2.2.33. Its MIT notice covers this adaptation.
Claude output style follows local, project, then user settings, selects only
`outputStyle`, and strips everything through the last colon. Missing or invalid
values fall through to the next settings file; when none supplies a valid value,
the result is null. Non-Claude providers do not read these files. Error logs
contain fixed messages rather than settings contents or process output.
